Use the Python library `rand-engine` (already installed) to generate two related tables and write them in the current directory as `customers.parquet` (1,000 rows, primary key column `customer_id`) and `orders.parquet` (5,000 rows, primary key `order_id`, foreign key column `customer_id` pointing at the customers' `customer_id`). Every order's `customer_id` must exist in `customers.parquet`.
