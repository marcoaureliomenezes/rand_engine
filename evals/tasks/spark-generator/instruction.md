Use the Python library `rand-engine` (already installed, together with `pyspark` and Java) to build a Spark DataFrame of 1,000 synthetic orders with two columns: `order_id`, a unique integer key counting up from 1, and `order_ref`, a unique text key that looks like `ORD-000001`. Run Spark locally with a single core (`local[1]`) and save the DataFrame as one parquet file, `orders.parquet`, in the current directory. Save the script that does it as `make.py` in the current directory, with a fixed seed, so that running it again gives the same file.
