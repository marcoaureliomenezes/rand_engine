# rand-engine in this project

Use this context when the project needs synthetic data for tests, demos, pipelines, files, streams, related tables, or Spark DataFrames.

## Install and import

```bash
pip install rand-engine
pip install "rand-engine[faker]"  # only for Faker pools
```

```python
from rand_engine import DataGenerator, RandSpecs, SparkGenerator

spec = {
    "user_id": {"method": "int_zfilled", "kwargs": {"length": 8}},
    "age": {"method": "integers", "kwargs": {"min": 18, "max": 80}},
}
users = DataGenerator(spec, seed=42).size(1_000).get_df()
```

Use `DataGenerator` for pandas DataFrames, record streams, and file output. Use `SparkGenerator` when the project already supplies a Spark session and Spark functions; PySpark is not installed by rand-engine.
