### Measured

Commands run from `worktrees/rand-engine/0.8.1/rc-1/wt-rc` with `POETRY_CACHE_DIR=<workspace>/.dadaia/tmp/poetry-cache`; scratch scripts and the patched copy live in `.dadaia/tmp/dd-sw-engineer-sr/20261020/` (`dtype.py`, `spark.py`, `bytes.py`, `drift.py`, `rt.py`, `take.py`, `proto.py`, `rest.py`, `e2e.py`, `dbx.py`, `tree/`).

- **M1 dtype, seam 1** (`dtype.py`, `drift.py`). `StringDtype("pyarrow")` writes `large_string`; the catalog and `expected_schema` say `string`; CSV, JSON and Parquet writers raise `schema drift: expected c: string, received c: large_string` (3 of 3 formats). `ArrowDtype(pa.string())` writes `string` and passes all 3. Both survive the anomaly path; both lose Arrow in `_assign_nulls` today (object + `None`, `is_string_dtype` is True for both on 2.2.3, contrary to the researcher's pandas 2.3.3 reading), fixed by the one-disjunct deletion above.
