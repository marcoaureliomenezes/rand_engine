# Security policy

Report a potential vulnerability through GitHub's [private vulnerability reporting
route](https://github.com/marcoaureliomenezes/rand_engine/security/advisories/new). GitHub may
ask you to sign in before you can create a private report. Use [GitHub
Issues](https://github.com/marcoaureliomenezes/rand_engine/issues) for ordinary bugs and support
questions.

Security fixes are evaluated against the latest published release line. Include the installed
version, affected environment, impact, and a minimal safe reproduction. Do not include
credentials, tokens, personal data, production data, or a destructive payload.
